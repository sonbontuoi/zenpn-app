## Windows

**[⬇ Download for Windows](https://github.com/sonbontuoi/zenpn-app/releases/latest/download/app-windows-x64-setup.exe)**

Copy the link:

```
https://github.com/sonbontuoi/zenpn-app/releases/latest/download/app-windows-x64-setup.exe
```

1. Open the downloaded `app-windows-x64-setup.exe` file.
2. If Windows says **Smart App Control** blocked the app, open **Windows Security** → **App & browser control** → **Smart App Control settings**, choose **Off** and confirm, then open the downloaded file again.
3. When Windows asks for administrator permission, click **Yes**.
4. If you see “Windows protected your PC”, click **More info** → **Run anyway**.
5. When it finishes, open **ZenPN** from the Start menu and sign in.

Windows 10 and 11, 64-bit.

## macOS

**[⬇ Download for macOS](https://github.com/sonbontuoi/zenpn-app/releases/latest/download/app-macos.dmg)**

Copy the link:

```
https://github.com/sonbontuoi/zenpn-app/releases/latest/download/app-macos.dmg
```

1. Open the downloaded `app-macos.dmg` file, then double-click **ZenPN**.
2. If macOS asks whether to open an app downloaded from the internet, click **Open**.
3. ZenPN moves itself into **Applications** and opens again.
4. When System Settings opens, turn on **ZenPN** under network extensions.
5. Sign in and click **Connect**. When macOS asks to add VPN configurations, click **Allow**.

macOS 14 Sonoma or later.
